# Risks and Technical Debt — OKR360 V1

> Status: TARGET V1; updated when a risk materializes, is mitigated, or when a debt item is resolved

Technical debt represents known suboptimal areas accepted temporarily to maintain momentum. Each item specifies mitigation/paydown strategies and the decision source.

Severity levels:

- **High:** impacts privacy, score correctness, or jeopardizes project completion;
- **Medium:** causes inconvenience or requires significant remediation effort;
- **Low:** minor impact.
